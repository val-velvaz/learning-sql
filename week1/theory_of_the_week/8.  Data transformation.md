# Data Transformation
Here we will dive into what SQL functios are and you will understand why they are a powerful tool that allows you yo perform meaningful operations on data stored in a database.

## String Functions
They help you to refine and format text for clarity and precision.

### UPPER/LOWER
Converts text to upper or lowercase, facilitating standarization.

```
SELECT UPPER(Name)
FROM Artists;
```

### CONCAT 
Joins strings together to create composite information

```
SELECT CONCAT(FirstName, ' ', LastName)
FROM Customers;
```

### SUBSTRING 
Extract parts of aa string, allowing focus on specific text segments

```
SELECT SUBSTRING(LastName, 1, 4)
FROM Customer;
```

## Mathematical Functions
Provide numeric manipulation.

### ROUND
Rounds numerical data to a specific number of decimal places

```
SELECT ROUND(UnitPrice, 1)
FROM Tracks;
```

### SUM 
Adds values in a set.

```
SELECT SUM(Total)
FROM Invoices
WHERE CustomerId = 5;
```

### AVG 
Calculates the mean average value of a column that is a number

```
SELECT AVD(Total)
FROM Invoices;
```

## Date and Time Functions
### Date FORMAT: 
Format date and time values as strings, allowing you to extract or display specific components like year, month, or day in a customized format.

```
SELECT LastName, FORMAT(BirthDate, 'MM-dd-yyyy')
FROM Employees
```

### GETDATE()
Retrieves the current data and time, applicable for timestamping.
```
SELECT GETDATE();
SELECT FORMAT(GETDATE(), 'MM/dd/yyyy');
```

### DATEDIFF
Calculates the difference between two dates, aiding in timeline analysis. Takes 3 arguments, the time format of the results, and two dates.

```
SELECT DATEDIFF(day, '2022-01-01', '2023-01-01');
```

## Aggregation Functions
Compile multiple data entries to provide summaries and averages.

### COUNT
Adds up to the number of rows. Findinf how many items or records there are.

```
SELECT COUNT(InvoiceId)
FROM Invoices
WHERE Total > 10;
```

### MIN/MAX
Identifies the smallest or largest value in a dataset.

```
SELECT MIN(UnitPrice)
FROM Tracks;
```
