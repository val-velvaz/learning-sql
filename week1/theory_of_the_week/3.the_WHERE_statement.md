# The WHERE clause
**WHERE** allows you to get the rows that meet specified criteria to pass through.

Its basic *syntax* is the following:
```
SELECT column1, column2
FROM table_name
WHERE condition;
```

## Comparison Operators
The WHERE clause can be combined with comparison operators to determine how number values relate:

* =: Equal to 
* != or <>: Not equal to
* <: Less than
* <=: Less than or equal to 
* >: Greater than 
* >= Greater than or equal to

## Logical Operators
You must use *logical operators* when dealing with more than one condition.

* AND: All conditions must be true
* OR: At least one of the conditions must be true
* NOT: The condition must be false

EXAMPLES 
```
SELECT Name, UnitPrice
FROM Tracks
WHERE UnitPrice >= 0.90 AND UnitPrice <= 1.10;

SELECT FirstName, LastName, Country
FROM Customers
WHERE Country = 'Germany' OR Country = 'France';

SELECT FirstName, LastName, Country
FROM Customers
WHERE NOT Country = 'USA';
```

## Combining WHERE with logical and comparison operators
EXAMPLES

```
-- Returns 51
SELECT ArtistId
FROM Artists
WHERE Name = 'Queen';

SELECT Title
FROM Albums
WHERE ArtistId = 51
ORDER BY Title ASC;
```
