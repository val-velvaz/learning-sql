# ORDER BY Clause
**ORDER BY** specifies one or more columns by which to sort the results of a query.

## Basic Syntax of ORDER BY

Here is the basic syntax of query using ORDER BY:
```
SELECT column1, column2
FROM table_name 
ORDER BY column1 [ASC|DESC], column2 [ASC|DESC];
```

## Sorting with Multiple Columns 
This is useful when you need to sort by more than one column.

```
SELECT Name, GenreId
FROM Tracks
ORDER BY GenreId, ASC, Name DESC;
```

## TIPS for using ORDER BY
1. Always specify each column's direction
2. Ensure data types are compatible for accurate sorting
3. Start by simple queries.
