# The SQL SELECT Statement
It is used to **select** data from a database.

Its syntax is the following:
```
SELECT column1, column2, ...
FROM table_name;
```

## Key questions when using a SELECT Statement
When writing a **SELECT** statement, always think about the following *key questions*:
1. **What** information do I need? (Specific *columns*)
2. **Where** is this information stored? (*tables*)
3. Do I need to **filter** the results? (*WHERE*)
4. How should the results be **organized**? (*ORDER BY*)
5. Do I need to **limit** how many rows are returned? (*LIMIT*)

## Understanding the SELECT statement
### SELECT
Specifies which columns you want to retrieve
```
SELECT FirstName, LastName
```
### FROM
Tells the database where to look for the data. It identifies the table(s) from which the data should be retrieved.
```
SELECT FirstName, LastName
FROM Employees;
```
### WHERE
Filter for refining responses. Narrows down your dataset based on specific conditions:
```
SELECT FirstName, LastName
FROM Employees
WHERE ReportsTo = 2;
```
### ORDER BY 
Arranges your output enabling you to present data scending or descending order based on one or multiple columns:

```
SELECT FirstName, LastName
FROM Employees
ORDER BY LastName ASC;
```
