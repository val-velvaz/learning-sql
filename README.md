### Is this your first time using a repository?
In order to use this repository on your computer you have to be sure you have Git installed. If you're using Linux you shouldn't really worry about it, as most distributions come with Git preinstalled. But if you're working with another operating system such as Windows, you may have to install it. So take these steps to do so:

1. Open your command prompt (cmd). You can do so by opening the Start menu and typing "cmd". Another way is to press `Windows + R` and type "cmd" as well.
2. Once the cmd is open, make sure you don't already have Git installed (otherwise, it doesn't make sense to download it, hahaha). You do this by typing `git --version` in the command prompt.
   - **If you already have Git**: the cmd will output a message with the installed version, something like `git version 2.45.0`.
   - **If it is not installed**: you will see a message saying that `git` is not recognized as a command.
3. Once you've made sure you don't have Git, go to the following link to download it: https://git-scm.com/install/windows. Make sure you select the appropriate download for your operating system (most modern computers use the 64-bit version).
4. Run the installer you just downloaded. You will see many options during the installation, but you can leave all of them as default by clicking **Next** until the end, then **Install** and **Finish**.
5. Close the cmd and open it again (this is important, otherwise it won't detect the new installation). Type `git --version` once more. If you now see a version number, Git is correctly installed.
6. Tell Git who you are. This is only needed once, and it labels the changes you make. Replace the examples with your own information:
  ```
  git config --global user.name “Your Name”
  git config --global user.email “youremail@example.com”
  ``` 
7. Choose a folder on your computer where you want to keep the repository (for example, `Documents`). In the cmd, move to that folder with the `cd` command:
  ```
  cd Documents
  ```
8. **Clone the repository**, which means downloading a copy of it to your computer:
  ```
  git clone https://github.com/val-velvaz/learning-sql.git
  ```
9. Move inside the new folder:
  ```
  cd learning-sql
  ```
Congratulations! You now have the whole repository on your computer and you can start exploring it. 

> **Tip:** if you ever want to get the latest updates I've made, run `git pull` inside the repository folder.
