# Modifying a View
SQL Server allows you to alter a view

Given a specific query:

```
CREATE VIEW View_EmployeeSales AS
SELECT e.FirstName,
e.LastName, 
SUM(i.Total) AS TotalSales
FROM Employee e 
JOIN Customer c ON e.EmployeeId = c.SupportRepId
JOIN Invoice i ON c.CustomerId = i.CustomerId
GROUP BY e.FirstName, e.LastName;
```

We can alter it by doing the following:
```
ALTER VIEW View_EmployeeSales AS
SELECT e.FirstName, 
e.LastName, 
e.Title, 
SUM(i.Total) AS TotalSales
FROM Employee e
JOIN Customer c ON e.EmployeeId = c.SupportRepId
JOIN Invoice i ON c.CustomerId = i.CustomerId
GROUP BY e.FirstName, e.LastName, e.Title;
```
We can do so by using the clause `ALTER VIEW`.

## Replacing a View
If you are unsure whether a view already exists, you can use the `CREATE OR ALTER VIEW`statement. 
``` 
CREATE OR ALTER VIEW View_EmployeeSales AS
SELECT e.FirstName, 
e.LastName, 
e.Title, 
SUM(i.Total) AS TotalSales
FROM Employee e
JOIN Customer c ON e.EmployeeId = c.SupportRepId
JOIN Invoice i ON c.CustomerId = i.CustomerId
GROUP BY e.FirstName, e.LastName, e.Title;
```

## Droping a View
There may coma a time when a view is no longer needed or becomes outdated. To altogether reomve it from the database, use `DROP VIEW`. 

``` 
DROP VIEW View_EmployeeSales;
```
