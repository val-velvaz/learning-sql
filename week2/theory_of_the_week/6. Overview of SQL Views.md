# What is a SQL view? 
* A view presents data from oen or more underlying tables - without storing itself
* It's a saved query that shows you specific slice of the data whenever you look through it

### Uses
* Simplify complex queries
* Extract the underlying data structure
* Present data customized to suit your business or analysis needs

## Basic Syntax for creating a View
```
CREATE VIEW View_EmployeeSales AS
SELECT e.FirstName, e.LastName, SUM(i.Total) AS TotalSales
FROM Employees e 
JOIN Customers c ON e.EmployeeId = c.SupportRepId
JOIN Invoices i ON c.CustomerId = i.CustomerId
GROUP BY e.FirstName, e.LastName;
```
