# Combining Queries
When combinign queries you can optimaze their performance, readibility, efficiency by blending transformations, filtering and aliases.

## Transformations
You transform data into rich insights by usign functions like SUM, COUNT or CONCAT.

```
SELECT CONCAT(c.FirstName, ' ', c.LastName) AS FullName,
    i.InvoiceDate,
    SUM(i.Total) AS TotalSales
FROM Customers c
JOIN Invoices i ON c.CustomerId = i.CustomerId
GROUP BY CONCAT(c.FirstName, ' ', c.LastName), i.InvoiceDate;
```

## Filtering
By using the WHERE clause and logical operators, you isolate data points that meet specific criteria, focusing the query results on your analysis goals.

```
SELECT p.Name, COUNT(pl.TrackId) AS TotalTrack
FROM Playlists p
JOIN PlaylistTracks pl ON p.PlaylistId = pl.PlaylistId
WHERE pl.TrackId IS NOT NULL
GROUP BY p.Name
ORDER BY TotalTrack DESC;
```

## Aliases
They transform complex table and column names into easily digestible tags, enhancing the overall readability of the queries.

```
SELECT ar.Name AS ArtistName, al.Title AS AlbumTitle
FROM Artists ar
JOIN Albums al ON ar.ArtistId = al.ArtistId;
```
## Keys to an efficient query
1. Understand the end goal
2. Select your tables
3. Apply Transformations
4. Filter Results
5. Use Aliases for Clarity
