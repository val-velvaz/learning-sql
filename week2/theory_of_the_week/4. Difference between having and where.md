# The difference between having and where
The main difference between them lies in **when** the filters are applied and whether they can evaluate aggregate functions (like `COUNT`, `SUM`,)

* `WHERE` filters individual rows *before* the data is grouped. It cannot use aggregate functions
* `HAVING` filters groups of data *after* the `GROUP BY` clause has been applied. It is specifically designed to evaluate aggregate functions.

EXAMPLE:
```
SELECT department, COUNT(employee_id) AS total_employees
FROM employees
WHERE status = 'Active'           -- 1. Filters individual rows first
GROUP BY department               -- 2. Groups active employees by department
HAVING COUNT(employee_id) > 10;   -- 3. Filters the resulting groups
```
