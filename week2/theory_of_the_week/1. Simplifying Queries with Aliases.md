# Simplifying Queries with Aliases
When writing queries, we can come along with names that does not indicate the kind of data they store. By using **SQL aliases** we can simplify the column names and table references, making the queries much more readable.

Alliases are a powerful tool to make your queries more reabable and maintainable.

## What are SQL Aliases?
They are temporary names given to columns or tables of a SQL query. They are designed to improve query readibility and context comprehension.

Exaple:
```
SELECT 
    c.CustomerId Customer_ID,
    c.FirstName Customer_FirstName,
    c.LastName Customer_LastName,
    i.InvoiceDate Invoice_Date,
    i.Total Invoice_Total
FROM Customers  c
JOIN Invoices  i
ON c.CustomerId = i.CustomerId
ORDER BY i.InvoiceDate DESC;
```

### Benefits
* Readability
* Conciseness 
* Clarity in Joins

### Tips
* Consistency
* Descriptiveness
